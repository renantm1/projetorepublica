# Brazil vector map

Source: [@svg-maps/brazil v2.0.0](https://www.npmjs.com/package/@svg-maps/brazil), by [svg-maps](https://github.com/VictorCazanave/svg-maps), based on [MapSVG's map of Brazil](https://mapsvg.com/maps/brazil).

License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The license text is included in `LICENSE-map.md`.

Modifications for REPÚBLICA: converted the supplied module to local JSON, uppercased state IDs and added label coordinates using path bounding boxes. Paths and viewBox are retained. All political and demographic values displayed over the map are fictional simulation parameters, separate from the geography.
